## 🚀 Getting Started

1. **Clone the Repository**
   ```bash
   git clone https://github.com/PriyaankPant/Demo-portfolio-writing.git
   cd Demo-portfolio-writing
   ```

2. **Open in Browser**
   - Simply open `index.html` in your preferred web browser
   - Or use a live server extension in VS Code for better experience

3. **Customize**
   - Update your information in `index.html`
   - Modify colors in `css/styles.css` using CSS variables
   - Add more interactivity in `js/script.js`

## 🎨 Customization

### Changing Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
    --primary-color: #6366f1;      /* Main brand color */
    --secondary-color: #8b5cf6;    /* Secondary color */
    --accent-color: #ec4899;       /* Accent color */
    /* ... more variables */
}
```

### Updating Content
- **Hero Section**: Update your name, tagline, and description in `index.html`
- **About Section**: Modify the about text and statistics
- **Projects**: Add your own projects with descriptions and links
- **Skills**: Update the skills categories and items
- **Contact**: Replace email and social links with your own
